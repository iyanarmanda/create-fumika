# create-fumika

Interactive CLI scaffolder to quickly bootstrap a new [Fumika Astro Blog](https://github.com/iyanarmanda/fumika) project.

## Quick Start

Run any of the following commands in your terminal:

```bash
# npm
npm create fumika@latest

# pnpm
pnpm create fumika@latest

# yarn
yarn create fumika

# bun
bun create fumika@latest

# deno
deno run -A npm:create-fumika@latest
```
